Roplex es el CMS headless ecommerce de Zauru. Se sienta entre el ERP (catálogo, existencias, facturación) y la tienda visual (Webstudio).

Esta documentación cubre el checkout: `POST /api/orders/create-ecommerce-order` y la configuración que ese endpoint necesita para funcionar.
